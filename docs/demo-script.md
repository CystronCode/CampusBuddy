# Five-minute company demonstration

Use a seeded **Demo Data** institution and real authenticated memberships. Do not imply the synthetic institution is a real college. If Supabase is not configured, use the isolated browser test harness only as clearly identified test evidence, not a deployed integration.

| Time | Action | Evidence to show |
|---|---|---|
| 0:00–0:35 | Sign in and open Home | Personalized section, compact day view, prominent question input and Demo Data labels |
| 0:35–1:15 | Ask “What class do I have tomorrow at 2 PM?” then “Where is that professor’s office?” | Effective-dated SQL result, faculty code resolution, contextual follow-up and source download |
| 1:15–1:50 | Open Canteen, choose ₹100 and Vegetarian, then Meal combinations | Available filtered items, actual totals, estimated protein, no hardcoded answers |
| 1:50–2:30 | Ask “What does the latest internal assessment circular say?” | Retrieved passages, page citations and deliberately conflicting dated notices |
| 2:30–3:05 | Ask “Can I attend Friday’s AI workshop without missing class?” | Event retrieval, section timetable and interval overlap, with both sources |
| 3:05–4:00 | Sign in as a separate administrator; upload a menu or notice | File preview, column mapping, row validation, confirmation and worker completion; then query the imported data |
| 4:00–4:35 | Open System Intelligence | Actual tool traces, source timestamps and counted records; keep technical complexity here |
| 4:35–5:00 | Run the MCP client | Protocol discovery and three real structured tool results using the same backend services |

If the selected day has no class or a seed notice is expired, show that honest empty state and choose a relevant date. Seed dates are relative to the chosen anchor; never change the answer manually for the presentation.

Close with the infrastructure story: one permission-aware service layer supports student UI, deterministic tools, document retrieval, administrator ingestion and external agent access. Present the limitations and staging acceptance checklist alongside the demonstration.
